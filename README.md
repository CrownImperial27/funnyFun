# Cheese Atlas

A React site about famous cheeses from around the world, with a built-in quiz game.

## Features

- Cheese wiki cards (origin, milk type, texture, flavor)
- Interactive quiz game about cheese facts
- Built with React + Vite
- Ready for GitHub Pages deployment

## Development

```bash
npm install
npm run dev
```

## Build

```bash
npm run build
```

## Deploy to GitHub Pages

```bash
npm run deploy
```

This project uses a relative Vite base path (`base: './'`) so the built app works reliably on GitHub Pages and other hosting paths.
